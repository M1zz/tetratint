Privacy Policy

TetraTint

Last updated: July 10, 2026

✓ TetraTint does not collect any personal data.

TetraTint is a developer tool that runs entirely on your Mac. Nothing is sent to a server, and the app contains no analytics, tracking or advertising.

Information we collect

None. The app doesn't ask for an account and doesn't collect identifiers, usage statistics, location or any other personal information.

Data stored on your device

  • Saved palettes and colors — the color values you save are kept in macOS UserDefaults on your Mac only and are never sent anywhere.
  • Exported files — .colorset, .xcassets and other exports are written only to the location you choose.
  • Copied code — generated code goes to the clipboard only when you click a copy button.

Screen color picker (eyedropper)

The eyedropper reads only the color value (RGB) of the spot you point at and uses it as the working color. It doesn't save or send screenshots, and the value stays in memory only while you use the app.

Third-party services

None. TetraTint doesn't talk to any third-party SDKs, analytics tools or cloud services.
