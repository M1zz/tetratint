TetraTint — Accessibility tooling for custom colors & fonts on macOS

What is TetraTint?

A macOS developer tool that takes care of the accessibility work Apple doesn't automate for custom colors and fonts. It derives the four light, dark and high-contrast variants of a custom color, checks WCAG contrast, simulates color vision deficiencies, and generates Dynamic Type code for custom fonts.

Requirements

  • macOS 13.0 (Ventura) or later
  • Permission to choose a save location when you export

FAQ

The four generated variants don't match my brand.

You can adjust each variant with the color picker on its card, and “Regenerate all” rebuilds them from the base color at any time.

Where are my saved palettes stored?

Only on your Mac — there's no cloud sync and nothing is uploaded. See the Privacy Policy for details.

Does the eyedropper save the colors it picks?

No. It reads only the color value of the spot you point at and uses it as the working color. No screen images are saved or sent.

Exported colors look different from system colors in my app.

The system color reference values come from the Human Interface Guidelines and can change between OS releases. In your app, always use the UIColor / Color APIs.
