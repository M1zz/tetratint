TetraTint · Privacy Policy

최종 업데이트 / Last updated: 2026-07-10

✓ TetraTint는 어떤 개인정보도 수집하지 않습니다.

TetraTint does not collect, store, or transmit any personal data.

TetraTint는 전적으로 사용자의 Mac에서만 동작하는 개발자 도구입니다. 서버로 전송되는 정보가 없으며, 분석·추적·광고 도구를 포함하지 않습니다.

수집하는 정보 · Information we collect

없음. TetraTint는 계정 로그인, 사용자 식별자, 사용 통계, 위치 등 어떠한 개인정보도 요구하거나 수집하지 않습니다.

None. The app requires no account and gathers no identifiers, analytics, or usage data.

기기에 저장되는 데이터 · Data stored on your device

  • 저장한 팔레트/색상 — 사용자가 저장한 색상 값은 macOS UserDefaults를 통해 사용자 기기에만 로컬로 보관됩니다. 외부로 전송되지 않습니다.
  • 내보내기 파일 — .colorset, .xcassets 등은 사용자가 직접 선택한 위치에만 저장됩니다.

Saved palettes are kept locally via macOS UserDefaults on your device only. Exported asset files are written solely to locations you choose.

화면 색상 추출(스포이드) · Screen color picker

스포이드 기능은 사용자가 가리키는 화면 지점의 색상 값(RGB)만 읽어 작업 색상으로 설정합니다. 화면 캡처를 저장하거나 외부로 전송하지 않으며, 색상 값은 앱 사용 중에만 메모리에 유지됩니다.

The eyedropper reads only the color value of the pixel you point at, to set it as the working color. No screenshots are stored or sent anywhere.

제3자 서비스 · Third-party services

없습니다. TetraTint는 어떤 제3자 SDK, 분석, 클라우드 서비스와도 통신하지 않습니다.

None. TetraTint does not integrate any third-party SDKs, analytics, or cloud services.
