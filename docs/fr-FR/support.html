TetraTint — Accessibilité des couleurs et polices personnalisées sur macOS

Qu’est-ce que TetraTint ?

Un outil de développement pour macOS qui prend en charge le travail d’accessibilité qu’Apple n’automatise pas pour les couleurs et les polices personnalisées. Il dérive les quatre variantes claire, sombre et à fort contraste d’une couleur personnalisée, vérifie le contraste WCAG, simule les déficiences de la vision des couleurs et génère le code Dynamic Type des polices personnalisées.

Variantes Contraste Vision des couleurs Dynamic Type

Configuration requise

  • macOS 14.0 (Sonoma) ou ultérieur
  • Autorisation de choisir un emplacement d’enregistrement lors de l’export

FAQ

Les quatre variantes générées ne correspondent pas à ma marque.

Vous pouvez ajuster chaque variante avec le sélecteur de couleur de sa carte, et « Tout régénérer » les recalcule à tout moment à partir de la couleur de base.

Où sont stockées mes palettes enregistrées ?

Uniquement sur votre Mac : il n’y a ni synchronisation cloud ni envoi de données. Pour en savoir plus, consultez la politique de confidentialité.

La pipette enregistre-t-elle les couleurs qu’elle prélève ?

Non. Elle lit uniquement la valeur de couleur de l’endroit que vous pointez et l’utilise comme couleur de travail. Aucune image de l’écran n’est enregistrée ni envoyée.

Les couleurs exportées ne ressemblent pas aux couleurs système dans mon app.

Les valeurs de référence des couleurs système proviennent des Human Interface Guidelines et peuvent changer d’une version du système à l’autre. Dans votre app, utilisez toujours les API UIColor / Color.
