TetraTint – Tillgänglighetsverktyg för egna färger och typsnitt på macOS

Vad är TetraTint?

Ett utvecklarverktyg för macOS som tar hand om tillgänglighetsarbetet som Apple inte automatiserar för egna färger och typsnitt. Det tar fram de fyra varianterna (ljus, mörk och med hög kontrast) av en egen färg, kontrollerar WCAG-kontrast, simulerar nedsatt färgseende och genererar Dynamic Type-kod för egna typsnitt.

Varianter Kontrast Färgseende Dynamic Type

Systemkrav

  • macOS 14.0 (Sonoma) eller senare
  • Behörighet att välja sparplats när du exporterar

Vanliga frågor

De fyra skapade varianterna passar inte mitt varumärke.

Du kan justera varje variant med färgväljaren på dess kort, och med ”Skapa om alla” byggs de upp på nytt från basfärgen när som helst.

Var lagras mina sparade paletter?

Enbart på din Mac. Det finns ingen molnsynkronisering och inget laddas upp. Läs mer i integritetspolicyn.

Sparar pipetten de färger den hämtar?

Nej. Den läser bara färgvärdet för den punkt du pekar på och använder det som arbetsfärg. Inga skärmbilder sparas eller skickas.

Exporterade färger ser annorlunda ut än systemfärgerna i min app.

Referensvärdena för systemfärger kommer från Human Interface Guidelines och kan ändras mellan OS-versioner. Använd alltid API:erna UIColor / Color i din app.
