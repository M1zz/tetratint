Privacy Policy

TetraTint

Last updated: 17 October 2026

✓ TetraTint does not collect any personal data.

TetraTint is a developer tool that runs entirely on your Mac. Your colours and palettes never leave it. The app sends only anonymous usage statistics, plus any feedback you choose to send. It contains no tracking or advertising.

Information we collect

The app doesn't ask for an account and doesn't collect your name, contact details, location or any other personal information.

Anonymous usage statistics

To learn how many people use TetraTint and which versions are still in use, the app sends anonymous statistics to Apple's iCloud (CloudKit), read only by the developer:

  • a random ID created when the app is installed (not linked to you, your Apple ID, your Mac or any other app; it changes if you reinstall)
  • app version, macOS version, and region and language setting
  • how many times the app was opened, the days it was opened, the install date, and how many days have passed since then

No colours, palettes, exported files or other content are included. Statistics are sent only if you are signed in to iCloud.

Feedback

If you send feedback from Settings, the message you write, along with the app version, macOS version and Mac model, is stored in Apple's iCloud (CloudKit) so the developer can read and reply to it. A contact email is included only if you type one. Nothing is sent unless you press send.

Data stored on your device

  • Saved palettes and colours — the colour values you save are kept in macOS UserDefaults on your Mac only and are never sent anywhere.
  • Exported files — .colorset, .xcassets and other exports are written only to the location you choose.
  • Copied code — generated code goes to the clipboard only when you click a copy button.

Screen colour picker (eyedropper)

The eyedropper reads only the colour value (RGB) of the spot you point at and uses it as the working colour. It doesn't save or send screenshots, and the value stays in memory only while you use the app.

Third-party services

None. TetraTint contains no third-party SDKs, analytics tools or advertising. The statistics and feedback above go only to Apple's iCloud (CloudKit).
