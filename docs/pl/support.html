Pomoc techniczna

TetraTint — Narzędzie dostępności dla własnych kolorów i czcionek na macOS

Czym jest TetraTint?

Narzędzie dla programistów na macOS, które wykonuje pracę nad dostępnością, jakiej Apple nie automatyzuje dla własnych kolorów i czcionek. Tworzy cztery warianty własnego koloru (jasny, ciemny i wysokokontrastowe), sprawdza kontrast WCAG, symuluje zaburzenia widzenia barw i generuje kod Dynamic Type dla własnych czcionek.

Warianty Kontrast Widzenie barw Dynamic Type

Wymagania

  • macOS 14.0 (Sonoma) lub nowszy
  • Możliwość wybrania miejsca zapisu podczas eksportu

Najczęstsze pytania

Cztery wygenerowane warianty nie pasują do mojej marki.

Każdy wariant możesz dopracować próbnikiem kolorów na jego karcie, a przycisk „Utwórz wszystko od nowa” w każdej chwili odtworzy je z koloru bazowego.

Gdzie są przechowywane moje zapisane palety?

Tylko na Twoim Macu. Nie ma synchronizacji z chmurą i nic nie jest przesyłane. Szczegóły znajdziesz w polityce prywatności.

Czy zakraplacz zapisuje pobierane kolory?

Nie. Odczytuje tylko wartość koloru punktu, który wskażesz, i używa jej jako koloru roboczego. Żadne obrazy ekranu nie są zapisywane ani wysyłane.

Wyeksportowane kolory wyglądają w mojej aplikacji inaczej niż kolory systemowe.

Wartości referencyjne kolorów systemowych pochodzą z Human Interface Guidelines i mogą zmieniać się w kolejnych wersjach systemu. W swojej aplikacji zawsze używaj API UIColor / Color.
