TetraTint — Přístupnost vlastních barev a písem na macOS

Co je TetraTint?

Nástroj pro vývojáře na macOS, který zvládne přístupnostní práci, jakou Apple u vlastních barev a písem automaticky nedělá. Odvodí čtyři varianty vlastní barvy (světlou, tmavou a obě vysoce kontrastní), zkontroluje kontrast podle WCAG, nasimuluje poruchy barevného vidění a vytvoří kód pro Dynamic Type pro vlastní písma.

Varianty Kontrast Barevné vidění Dynamic Type

Požadavky

  • macOS 14.0 (Sonoma) nebo novější
  • Možnost zvolit při exportu místo uložení

Časté dotazy

Čtyři vytvořené varianty neladí s mou značkou.

Každou variantu můžete upravit výběrem barvy na její kartě a tlačítko „Vytvořit vše znovu“ je kdykoli znovu odvodí ze základní barvy.

Kde jsou uložené moje palety?

Pouze ve vašem Macu. Neprobíhá žádná synchronizace přes cloud a nic se nenahrává. Podrobnosti najdete v Zásadách ochrany osobních údajů.

Ukládá kapátko barvy, které vybere?

Ne. Přečte jen hodnotu barvy místa, na které ukážete, a použije ji jako pracovní barvu. Žádné snímky obrazovky se neukládají ani neodesílají.

Exportované barvy v mé aplikaci vypadají jinak než systémové.

Referenční hodnoty systémových barev pocházejí z Human Interface Guidelines a mohou se mezi verzemi systému měnit. Ve své aplikaci vždy používejte API UIColor / Color.
