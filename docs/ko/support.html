TetraTint — 커스텀 컬러·폰트를 위한 macOS 접근성 개발 도구

TetraTint란?

애플 시스템이 자동으로 해 주지 않는 접근성 작업을 대신하는 macOS 개발자 도구입니다. 커스텀 컬러의 라이트·다크·고대비 4종 변형 생성, 대비(WCAG) 판정, 색각이상 시뮬레이션, 커스텀 폰트의 Dynamic Type 대응 코드 생성을 지원합니다.

변형 생성 대비 검사 색각 시뮬레이션 Dynamic Type

요구 사항

  • macOS 13.0 (Ventura) 이상
  • 내보내기를 쓸 때 파일 저장 위치 선택 권한

자주 묻는 질문

자동으로 만든 4종 변형이 브랜드 톤과 안 맞아요.

각 변형 카드의 컬러 피커로 하나씩 고칠 수 있고, “전체 다시 생성”으로 언제든 기준 색에서 다시 만들 수 있습니다.

저장한 팔레트는 어디에 보관되나요?

사용자 Mac에만 저장됩니다(클라우드 동기화·전송 없음). 자세한 내용은 개인정보처리방침을 참고하세요.

스포이드로 추출한 색이 저장되나요?

아니요. 가리킨 지점의 색상 값만 읽어 작업 색상으로 쓰며, 화면 이미지는 저장하거나 전송하지 않습니다.

내보낸 색이 실제 앱에서 시스템 색과 다르게 보여요.

시스템 컬러 레퍼런스 값은 HIG 문서 기준이며 OS 릴리스마다 달라질 수 있습니다. 실제 앱에서는 늘 UIColor / Color API를 쓰세요.
