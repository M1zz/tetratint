TetraTint

최종 업데이트: 2026-10-17

✓ TetraTint는 어떤 개인정보도 수집하지 않습니다.

TetraTint는 사용자의 Mac 안에서만 동작하는 개발자 도구입니다. 색상과 팔레트는 Mac 밖으로 나가지 않습니다. 밖으로 보내는 것은 익명 사용 통계와 사용자가 직접 보내는 피드백뿐이며, 추적·광고 도구는 들어 있지 않습니다.

수집하는 정보

계정 로그인을 요구하지 않으며, 이름·연락처·위치 같은 개인정보를 수집하지 않습니다.

익명 사용 통계

TetraTint를 몇 명이 쓰는지, 어떤 버전이 아직 쓰이는지 알기 위해 다음 익명 통계를 Apple iCloud(CloudKit)로 보냅니다. 개발자만 읽습니다.

  • 설치할 때 만든 무작위 ID (사용자·Apple ID·Mac·다른 앱과 연결되지 않으며, 다시 설치하면 바뀝니다)
  • 앱 버전, macOS 버전, 지역·언어 설정
  • 앱을 연 횟수, 앱을 연 날, 설치한 날짜와 설치 후 지난 날수

색상, 팔레트, 내보낸 파일 같은 내용은 포함하지 않습니다. iCloud에 로그인되어 있을 때만 보냅니다.

피드백

설정에서 피드백을 보내면 작성한 내용과 앱 버전, macOS 버전, Mac 기종이 Apple iCloud(CloudKit)에 저장되어 개발자가 읽고 답장할 수 있습니다. 회신 이메일은 직접 입력했을 때만 함께 저장됩니다. 보내기를 누르기 전에는 아무것도 전송되지 않습니다.

기기에 저장되는 데이터

  • 저장한 팔레트·색상 — 저장한 색상 값은 macOS UserDefaults를 통해 사용자 기기에만 보관되며 밖으로 전송되지 않습니다.
  • 내보내기 파일 — .colorset, .xcassets 등은 사용자가 직접 고른 위치에만 저장됩니다.
  • 코드 복사 — 복사 버튼을 누를 때만 생성된 코드가 클립보드에 들어갑니다.

화면 색상 추출(스포이드)

스포이드는 사용자가 가리킨 화면 지점의 색상 값(RGB)만 읽어 작업 색상으로 씁니다. 화면을 캡처해 저장하거나 전송하지 않으며, 색상 값은 앱을 쓰는 동안에만 메모리에 남습니다.

제3자 서비스

없습니다. TetraTint에는 제3자 SDK, 분석 도구, 광고가 들어 있지 않습니다. 위의 통계와 피드백은 Apple iCloud(CloudKit)로만 전송됩니다.
