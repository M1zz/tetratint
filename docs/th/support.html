TetraTint — เครื่องมือเข้าถึงสีและฟอนต์กำหนดเองบน macOS

TetraTint คืออะไร

เครื่องมือสำหรับนักพัฒนาบน macOS ที่ช่วยทำงานด้านการเข้าถึงซึ่ง Apple ไม่ได้ทำให้อัตโนมัติสำหรับสีและฟอนต์ที่กำหนดเอง สร้างสี่เวอร์ชัน ทั้งสว่าง มืด และคอนทราสต์สูงจากสีที่คุณกำหนด ตรวจคอนทราสต์ตาม WCAG จำลองภาวะตาบอดสี และสร้างโค้ด Dynamic Type ให้ฟอนต์กำหนดเอง

เวอร์ชันสี คอนทราสต์ การมองเห็นสี Dynamic Type

ความต้องการของระบบ

  • macOS 14.0 (Sonoma) ขึ้นไป
  • สิทธิ์ในการเลือกตำแหน่งบันทึกเมื่อส่งออก

คำถามที่พบบ่อย

สี่เวอร์ชันที่สร้างขึ้นไม่เข้ากับแบรนด์ของฉัน

คุณปรับแต่ละเวอร์ชันได้ด้วยตัวเลือกสีบนการ์ดของเวอร์ชันนั้น และกด “สร้างใหม่ทั้งหมด” เพื่อสร้างใหม่จากสีตั้งต้นได้ทุกเมื่อ

จานสีที่บันทึกไว้เก็บอยู่ที่ไหน

เก็บไว้บน Mac ของคุณเท่านั้น ไม่มีการซิงก์ผ่านคลาวด์และไม่มีการอัปโหลดใดๆ ดูรายละเอียดได้ในนโยบายความเป็นส่วนตัว

หลอดดูดสีบันทึกสีที่ดูดไว้หรือไม่

ไม่ หลอดดูดสีอ่านเฉพาะค่าสีของจุดที่คุณชี้และนำไปใช้เป็นสีที่ใช้งาน ไม่มีการบันทึกหรือส่งภาพหน้าจอ

สีที่ส่งออกดูต่างจากสีของระบบในแอปของฉัน

ค่าอ้างอิงของสีระบบมาจาก Human Interface Guidelines และอาจเปลี่ยนไปตามเวอร์ชันของ OS ในแอปของคุณ ให้ใช้ API UIColor / Color เสมอ

ติดต่อเรา

ส่งรายงานข้อบกพร่อง ไอเดียฟีเจอร์ และคำถามมาทางอีเมลได้เลย โดยปกติเราจะตอบกลับภายใน 2–3 วัน
