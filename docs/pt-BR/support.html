TetraTint — Acessibilidade para cores e fontes personalizadas no macOS

O que é o TetraTint?

Uma ferramenta para desenvolvedores de macOS que cuida da acessibilidade que a Apple não automatiza para cores e fontes personalizadas. Ela gera as quatro variantes clara, escura e de alto contraste de uma cor personalizada, confere o contraste WCAG, simula deficiências de visão de cores e cria código Dynamic Type para fontes personalizadas.

Variantes Contraste Visão de cores Dynamic Type

Requisitos

  • macOS 14.0 (Sonoma) ou posterior
  • Permissão para escolher onde salvar ao exportar

Perguntas frequentes

As quatro variantes geradas não combinam com a minha marca.

Você pode ajustar cada variante com o seletor de cor no cartão dela, e “Gerar tudo de novo” refaz todas a partir da cor base a qualquer momento.

Onde ficam guardadas as minhas paletas salvas?

Somente no seu Mac: não há sincronização na nuvem e nada é enviado. Veja os detalhes na Política de Privacidade.

O conta-gotas salva as cores que captura?

Não. Ele lê apenas o valor de cor do ponto que você indica e o usa como cor de trabalho. Nenhuma imagem da tela é salva ou enviada.

As cores exportadas parecem diferentes das cores do sistema no meu app.

Os valores de referência das cores do sistema vêm das Human Interface Guidelines e podem mudar entre versões do sistema. No seu app, use sempre as APIs UIColor / Color.
